# CaminoSeguro
🦯 **CaminoSeguro IA** | Prototipo de asistencia para personas con discapacidad visual que utiliza visión artificial y aprendizaje automático para identificar obstáculos, escaleras, desniveles y calles en tiempo real, proporcionando alertas sonoras. Desarrollado en Python y JavaScript, con versiones de escritorio y web para dispositivos móviles.
